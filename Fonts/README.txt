SAO FONT
========
Put a font file named exactly  SAOUI.ttf  in this folder, then type /reload in game.
SAO Frames detects it automatically and uses it for all its text.

Suggested fonts (download them yourself; check each font's license):
 - "SAO UI" by DarkBlackSwords - fan-made font based on the Sword Art Online interface
   (free download, e.g. via fontmeme.com/sword-art-online-font). Rename the regular
   weight to SAOUI.ttf.
 - "Rajdhani" (Google Fonts, SIL Open Font License) - a free squared techno/HUD look-alike.
   Rename Rajdhani-SemiBold.ttf (or Medium) to SAOUI.ttf.

Turn the font off again with /sao font or in the options window (/sao).
If the file is missing or can't be read, SAO Frames keeps its normal fonts.
